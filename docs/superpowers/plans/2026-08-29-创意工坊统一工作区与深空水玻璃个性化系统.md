# 创意工坊统一工作区与深空 Liquid Glass 个性化系统规划

> **For agentic workers:** 实施时按本文顺序执行；先保护现有脏工作树与用户数据，再通过测试驱动完成组件拆分、迁移、视觉验收和更新记录。未经用户明确授权不得提交 Git。

**Goal:** 把现有“主工作区”和“创意工坊”合并为唯一的“创意工坊”，建立三域统一工作台，并增加设备本地图片/短视频壁纸、深空 Liquid Glass 功能层和十套主题的新视觉系统。

**Architecture:** 页面层统一到 `studio`，左侧承载会话/文件，中央承载四种真实创作模式，右侧承载上下文感知检查器。个性化层通过 owner-scoped IndexedDB 保存壁纸，通过统一 Theme Registry、WallpaperLayer 与 LiquidGlassSurface 驱动背景、星轨、玻璃和状态能谱。

**Tech Stack:** Next.js 16.2.4、React 19.2.4、TypeScript 5、Motion 12、Three.js / React Three Fiber、GSAP、CSS `backdrop-filter`、SVG filters、IndexedDB、Node `node:test`。

参考原则：

- [Apple Liquid Glass Materials](https://developer.apple.com/design/human-interface-guidelines/materials)：玻璃应主要承载导航和功能控件，而非覆盖全部内容层。
- [MDN backdrop-filter](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/backdrop-filter)：建立稳定的跨浏览器模糊基线。
- [MDN OKLCH](https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Values/color_value/oklch)：用于主题混色、智能取色和亮度一致性。

## Global Constraints

- 本轮只创建和确认规划文档，不实现页面。
- 实施时保留当前会话、消息、附件、任务、协作 Run、OPC 会话、用户账号和服务器主题设置。
- 不重置、不覆盖、不批量格式化当前大量未提交工作。
- 不用浅白通用 glassmorphism 取代现有深空品牌；Liquid Glass 必须使用主题 tint、镜面细线、发光边缘和深色阅读基线。
- 不引入 WebGL 玻璃，避免与现有 Three.js 星空争抢 GPU。
- 壁纸只保存在当前设备，不上传服务器。
- 页面生成完成后必须新增真实 `更新md/`，未执行的检查不得写成通过。

## 1. 页面合并与信息架构

### 1.1 导航与兼容迁移

- 删除顶部导航中的“主工作区”，仅保留“创意工坊”。
- 统一使用内部页面 key `studio`。
- 历史 `chat`、设置中的 `opc` 起始页自动迁移到 `studio`。
- `PageTransition` 删除独立 Chat 页映射，改为单一 `CreativeWorkspace`。
- 不删除或重建已有会话、消息、文件、任务、协作 Run 和 OPC 数据。
- 原 `ChatFlow`、`CreativeStudio` 暂时保留兼容导出，逐步拆出可复用核心，避免一次性重写已有链路。

### 1.2 三域统一工作台

宽屏默认布局：

| 区域 | 默认宽度 | 可调范围 | 职责 |
|---|---:|---:|---|
| 左侧会话/文件坞 | 280px | 240–360px | 会话、文件、搜索、新对话、账户 |
| 中央主创作流 | 自适应 | 最小 640px | 消息、结果、工作流、协作阶段、底部输入 |
| 右侧上下文检查器 | 420px | 340–520px | 根据当前模式显示参数、任务、资料、产物、轨迹、审校 |

两侧均支持：

- 收起为 52–56px 功能轨。
- Pointer 拖拽调宽。
- 键盘调整宽度。
- 本地记忆开合与尺寸。
- Escape 关闭浮层并恢复焦点。

响应式：

- `>= 1440px`：三栏完整停靠。
- `1180–1439px`：左侧窄轨 + 中央 + 右侧检查器。
- `960–1179px`：左侧停靠，右侧改为覆盖抽屉。
- `< 960px`：中央单列，左右区域均改为侧滑层。
- 布局降级必须先收侧栏，不能把中央创作区压到 640px 以下。

### 1.3 顶部创意参数条

放置在全局导航下方，使用深空 Liquid Glass 材质，包含：

- 风格
- 运镜
- 图像参数
- 时长
- 画幅
- 当前 CreativeContext 摘要
- “插入到输入”动作
- “重置参数”动作

参数选择立即更新结构化上下文，但不自动污染文本草稿。

```ts
export type CreativeContext = {
  revision: number;
  styleId: string | null;
  styleLabel: string;
  cameraMoveId: string | null;
  cameraMoveLabel: string;
  selectedParams: string[];
  durationSeconds: number;
  aspect: "21:9" | "16:9" | "4:3" | "1:1" | "3:4" | "9:16" | "9:21" | "adaptive";
  promptFragment: string;
};
```

- 四种底部模式都接收同一 CreativeContext。
- 点击“插入到输入”时，才把规范化提示词片段写入当前输入框。
- 重复插入使用上下文 revision 去重，避免产生重复标签。

### 1.4 底部统一输入工作栏

固定四模式：

```ts
export type CreativeWorkspaceMode =
  | "coze"
  | "assistant"
  | "workflow"
  | "collaboration";
```

对应文案：

- Coze 创作
- 单助手
- 工作流
- 协作编排

行为边界：

- Coze 创作：沿用附件上传、可靠任务队列、状态查询和媒体结果。
- 单助手：沿用账户模型和 `/api/model/chat`。
- 工作流：沿用六个工作流，并兼容此前规划的风格研究运行工作台。
- 协作编排：沿用多角色、预算、审校、人工确认和可靠任务投递。
- 四种模式各自保存草稿；切换模式不得清空其他模式输入。
- 发送按钮、附件、参数插入和错误状态随当前模式变化。

### 1.5 上下文感知检查器

- Coze 模式：任务状态、生成参数、附件、图片/视频作品和后续建议。
- 单助手：CreativeContext、引用、模型信息、会话摘要和输出动作。
- 工作流：计划、资料、产物、轨迹。
- 协作编排：项目、角色、阶段、审校、风险和最终指令。
- 当前模式没有详情时显示有明确下一步的空状态，不保留无意义空面板。

## 2. Liquid Glass 与壁纸系统

### 2.1 分层顺序

```text
主题基础色
→ 图片/视频壁纸
→ 压暗、渐晕、色温调整
→ 星尘与轨道叠加
→ 标准内容层
→ Liquid Glass 功能层
→ 临时弹层和通知
```

Liquid Glass 仅用于：

- 顶部导航
- 创意参数条
- 左侧会话坞
- 右侧检查器
- 底部输入工作栏
- 设置工作室
- Popover、菜单和临时控制

正文消息、长报告、表格和产物正文继续使用稳定深色标准材质，禁止层层嵌套玻璃。

### 2.2 渐进增强渲染

```ts
export type LiquidGlassVariant = "bar" | "panel" | "capsule" | "popover";

export type LiquidGlassSurfaceProps = {
  variant: LiquidGlassVariant;
  interactive?: boolean;
  energyState?: ThemeEnergyState;
  className?: string;
  children: React.ReactNode;
};
```

渲染分级：

1. 无 `backdrop-filter`：使用近不透明深色背景、边框和阴影。
2. 支持 `backdrop-filter`：使用 blur、saturate、brightness 和 theme tint。
3. Chromium 增强：增加 SVG `feDisplacementMap` 边缘折射和轻微 RGB 色散。
4. Safari/Firefox：自动保持高质量 blur fallback。
5. 不引入 WebGL，避免与现有 Three.js 星空争抢 GPU。
6. 只为 bar、panel、capsule、popover 准备有限的可复用折射 geometry，不为每个控件生成独立滤镜。

发光边缘必须保留：

- 主题色外辉光
- 白色镜面细线
- 冷暖色折射边缘
- 交互时短暂增强
- reduced-motion 下取消移动和扫光，但保留静态玻璃层次

### 2.3 玻璃预设

```ts
export type GlassPreset = "clear" | "balanced" | "deep";

export type GlassSettings = {
  preset: GlassPreset;
  blurPx: number;
  opacity: number;
  refraction: number;
  edgeGlow: number;
  wallpaperDim: number;
  smartTint: number;
  reduceTransparency: boolean;
};
```

范围：

- blur：8–32px
- opacity：0.12–0.42
- refraction：0–36
- edge glow：0.10–0.45
- wallpaper dim：0–0.60
- smart tint：0–0.25

默认值：

| 预设 | Blur | Opacity | Refraction | Edge glow | Dim |
|---|---:|---:|---:|---:|---:|
| 清透 | 12 | 0.14 | 32 | 0.18 | 0.20 |
| 平衡 | 18 | 0.22 | 24 | 0.24 | 0.32 |
| 深邃 | 24 | 0.34 | 16 | 0.30 | 0.48 |

用户先选择三档预设；高级区再展开具体滑杆。

### 2.4 壁纸媒体

支持：

- 本地 JPG、PNG、WebP、AVIF
- HTTPS 图片 URL
- 本地 MP4、WebM
- HTTPS MP4、WebM URL
- 视频最长 30 秒
- 视频固定静音、循环
- 视频必须提供暂停/继续控制

默认限制：

- 图片最大 25 MiB
- 视频最大 150 MiB
- 最大边长 4096px
- 视频最大 3840×2160
- 超限时给出明确错误，不静默压缩失败

```ts
export type WallpaperAppearance = {
  assetId: string | null;
  aspect: "16:9" | "3:2";
  fit: "cover" | "contain";
  focalX: number;
  focalY: number;
  dim: number;
  starfieldOpacity: number;
  orbitOpacity: number;
  smartTintEnabled: boolean;
  smartTintStrength: number;
};
```

- cover 模式支持拖动焦点。
- contain 模式使用主题色模糊延展填充空白。
- 星尘和轨道默认保留为低透明叠加层，可独立调节或关闭。
- 页面隐藏、`prefers-reduced-motion`、省电/数据节省状态下暂停视频。
- 视频壁纸启用时，星尘粒子数量默认降低 40%。

### 2.5 当前设备存储

不上传服务器。

```ts
export type WallpaperAsset = {
  id: string;
  ownerScope: string;
  kind: "image" | "video";
  source: "local" | "url";
  mimeType: string;
  blob?: Blob;
  url?: string;
  posterBlob?: Blob;
  width: number;
  height: number;
  durationMs: number | null;
  createdAt: number;
  lastUsedAt: number;
};
```

- IndexedDB：`tszh-personalization`
- Object store：`wallpapers`
- 使用 `ownerScope()` 隔离访客与不同账号。
- localStorage/UserPreferences 只保存 assetId 和显示配置，不保存 Blob。
- 页面卸载或切换壁纸时 revoke Object URL。
- 外部 URL 只允许 HTTPS，拒绝带账号密码的 URL。
- URL 媒体无法通过 CORS 读取像素时仍可显示，但禁用智能取色并解释原因。
- 删除当前壁纸时先切回主题背景，再删除 IndexedDB Blob。

### 2.6 智能取色

- 默认关闭。
- 只提取一个主色，不自动重算整套主题。
- 采用 OKLCH 控制亮度与饱和度。
- 默认以 15% 混入 `--glass-tint` 和 `--glass-edge-accent`。
- 最大混入 25%。
- 若混色导致文本或边框低于对比要求，自动降低混入强度。
- 视频只从 poster frame 取色，不逐帧改变主题。

### 4.3 极光能谱状态

```ts
export type ThemeEnergyState = "idle" | "running" | "thinking" | "peak";
```

极昼弧光：

- Idle：薄荷绿
- Running：冰蓝
- Thinking：靛紫
- Peak：短暂紫红高光

磁暴极光：

- Idle：电蓝
- Running：离子紫
- Thinking：洋红
- Peak：玫红短脉冲

规则：

- 状态只能由真实运行状态驱动。
- 禁止使用 `setInterval` 无意义循环能谱。
- Peak 最长 900ms，随后回到 running 或 idle。
- reduced-motion 下取消迁移动画，直接切换静态 token。
- 其他八套主题仍定义 energy token，但默认变化更克制。

### 4.4 Theme Registry

把 `THEMES` 从 SettingsDrawer 移到 `app/lib/theme-registry.ts`：

```ts
export type ThemeDefinition = {
  id: ThemeId;
  name: string;
  description: string;
  colors: {
    deep: string;
    panel: string;
    surface: string;
    foreground: string;
    muted: string;
    primary: string;
    primarySoft: string;
    cool: string;
    aurora: string;
  };
  glass: {
    tint: string;
    border: string;
    highlight: string;
    shadow: string;
  };
  energy: Record<ThemeEnergyState, string>;
};
```

所有主题验收：

- 普通正文对背景不低于 4.5:1
- 大字不低于 3:1
- 弱文字仍需可辨识
- 焦点环不能只依赖颜色
- error/success 不被主题主色覆盖
- Glass clear/balanced/deep 三档均需单独检查
- 智能取色开启后重新检查对比度

- 只创建新的规划 Markdown，不在本轮实现页面。
