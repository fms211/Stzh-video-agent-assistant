# Stzh·video agent assistant 1.40

2026-10-01 · Web 创作工作台

**从一张聚焦灵感的观测卡，到承载创作过程的完整工作台。**

新对话以星环为视觉中心，第一条被接受的请求让玻璃框展开，标题缩小移向左上，消息流轻量出现。已有历史会话直接打开阅读布局。输入法组合输入、草稿和任务流程继续使用真实提交状态。

在“个性化 → 对话边缘光”中调节强度、边缘敏感度、光锥、圆角、辉光范围、底色和三种渐变色。五项基础滑杆对齐 React Bits BorderGlow 官网 Customize 范围。本站将外侧光晕收在内侧以适配工作区裁切；新增边宽与有限染色选项，默认染色为零。参数实时预览并按账户保存。

激活模式标签和展开侧栏增加弱辉光；任务完成、模型连接验证成功在真实状态变化时短暂亮起。历史成功记录保持静态。减少动画时不播放追光、缩放、位移和状态闪亮。

本版同时整合工作区四模式、模型与角色中心、项目记忆与上下文检查、任务中心、统计与画廊的当前 Web 实现。手机端阶段五与付费媒体验证继续延期。
