# Stzh·video agent assistant 1.40

2026-10-01 · Web creative workspace

**Start with a focused observation card. Open a workspace with your first intent.**

A new conversation centers a compact glass surface near the orbit. The first accepted request expands it, moves the title to the upper left and reveals the message flow. Existing conversations open directly into the reading layout. IME composition, drafts and task progress follow actual submission state.

Appearance → Conversation border glow provides live controls for intensity, edge sensitivity, cone spread, radius, glow extent, background and three gradient colors. The five basic sliders match React Bits BorderGlow Customize ranges. The workspace adapts the outer glow to an inner edge to respect clipping; border width and limited tint are local additions, with tint disabled by default. Preferences are saved per account.

Active mode tabs and open sidebar edges receive softer highlights. Task completion and a successful model connection check briefly glow on an actual state change; historical success remains static. Reduced-motion preferences disable tracking, geometry motion and status flashes.

This release also publishes the current Web implementation of four creation modes, the model and role center, project memory and context inspection, tasks, statistics and gallery. Phase-five mobile development and paid media verification remain deferred.
