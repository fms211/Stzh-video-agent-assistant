## 已确认并修复的问题

同账户打开过期非当前会话时，读取可以先由服务器生成，清理随后完成，浏览器最后处理旧响应。旧版会重新写回正文缓存或历史索引；这是一项已复现的删除正确性问题。账户归属检查和服务端墓碑仍有效，没有证据表明它形成跨账户攻击或服务端数据重建。

修复采用本机按账户持久化删除标记：正文读取、历史列表、当前会话切换、写入及上传确认提交前检查。其他标签页读取同源标记；其他账户相同ID不受影响。严格读取提示已清理，后台恢复不恢复内容。作品、记忆、研究和协作的清理范围未扩大。

新增行为用例先4项失败，再增加迟到上传确认，共5项通过；一次集中相关回归43/43。`npm run build`编译/类型/导出通过；默认环境带入开发API地址，因此另做同源预览构建。最终运行/页面结果见[交接清单](../handoffs/stage4-web-20261004.md)，不把编译成功等同于页面验收。
