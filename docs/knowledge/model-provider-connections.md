# 模型厂商连接与本机预览

最近补充：2026-09-30，第45批模型中心请求生命周期；真实厂商连接最近核验为第44批，本批没有重复收费连接验证。实现依据：`app/lib/provider-presets.ts`、`app/components/ModelRoleCenter.tsx`、`server/lib/provider-discovery.js`、`server/lib/provider-host.js`、`server/routes/creative-agent.js`及相应实际HTTP记录。

官网链接用于打开厂商控制台，API地址用于发送请求。两者独立；输入官网地址不会自动变成API地址。厂商预设提供初始官网、API地址和协议，用户可修改。模型标识来自“获取模型”读取的厂商列表；没有列表接口时仍可手填。

## 正常流程与状态

1. 选择厂商，核对API地址和协议，填写该厂商密钥。
2. “获取模型”仅调用模型列表接口，不保存连接或生成内容。选择返回的模型后再保存。
3. 服务端加密保存密钥，响应只给密钥存在状态和末尾提示；原密钥不返回浏览器。
4. “连接验证”会调用一次文字模型。列表可读不代表文字调用已验证；只有当前连接验证成功才记录verifiedAt。
5. 改变连接地址、协议、模型或密钥等连接参数后，旧验证失效。使用已保存密钥获取列表时，不能把该密钥转发到改后的地址；新地址须重新填写密钥。
6. 中心刷新只应用最新请求的结果；离开页面或切换账户后取消该次请求，迟到回复不改写新页面。保存、删除、验证和角色操作使用发起时捕获的账户连接，同一次操作进行中拒绝重复提交。
7. 写入或模型请求发生网络/服务端错误时，先只读核对当前列表，提示用户确认实际结果；错误响应不能证明此前动作没有生效。不自动重复写入、连接验证或角色模型调用。本地取消不证明服务器或上游动作已经撤销。

## DNS网关与精确例外

默认拒绝本机、内网及特殊地址。模型列表先检查全部DNS结果，再将核准IP固定到本次连接，保持正常TLS证书/域名校验，并拒绝重定向。

本机当前`api.xiaomimimo.com`解析为`172.29.0.66`，原默认规则因此返回“API地址解析到本机或内网”。部署者核实网关后可设置服务端环境变量`STZH_TRUSTED_MODEL_GATEWAYS`，其JSON结构例如：

```json
{"api.xiaomimimo.com":["172.29.0.66"]}
```

例外要求HTTPS、标准443端口、准确域名和全部解析IP均在名单内；不匹配域名、端口、IP、混入其他地址或配置格式错误仍拒绝。浏览器表单不能设置该例外。生产没有默认例外；此IP是本机现场值，其他环境须重新核对，不能直接照搬。原有`STZH_ALLOW_PRIVATE_MODEL_URLS`仍属于部署者主动开启本地模型的配置，本次预览保持为0。

## 18080验收预览

`scripts/stage4-local-preview.cjs`沿用`output/stage4/isolated-data/stzh.db`，只开放MiMo官方`GET /v1/models`和`POST /v1/chat/completions`。文字仅允许`mimo-v2.6-flash`、关闭思考、输出上限4096、纯文字消息和无工具调用；其他厂商及媒体接口在此预览中会显示明确限制说明。正式服务器的厂商选择功能没有这一验收预览名单限制。

## 失败时核对位置

- DNS拦截：查真实解析结果、名单域名/IP/协议；不是Coze配额错误。
- 认证拒绝：核对当前厂商密钥及模型列表权限，响应不回显上游密钥。
- 模型列表404/405：核对API基础地址、协议和厂商是否提供列表，必要时手填。
- 保存失败：核对当前服务的加密材料配置，不能用重新推理来解决保存问题。
- HTTP500或回包丢失：页面先读当前列表，保留改稿并提示核对后决定是否重试；只读失败时显示“当前结果尚未确认”，不把它当作可安全重发的证据。明确的4xx输入错误保留改稿，不附带自动重复请求。
- 预览限制：当前预览仅开放上面的MiMo文字范围；不能将此限制当作厂商额度不足。
- Coze HTTP429/code4404：独立的限流/配额问题；MiMo列表恢复不代表Coze已恢复。
