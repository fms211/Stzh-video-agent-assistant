## 背景与目标

按 `docs/superpowers/plans/2026-08-29-创意工坊统一工作区与深空水玻璃个性化系统.md` 实施：把「主工作区」与「创意工坊」合并为唯一创意工坊，建立三域统一工作台；新增设备本地图片/短视频壁纸、深空 Liquid Glass 功能层、十套主题重构与能谱状态。

## 用户可感知变化

1. 顶部导航删除「主工作区」，仅保留「创意工坊」（studio）；`chat`/`opc` 起始页自动迁移到 `studio`；对话/协作编排并入创意工坊。
2. 创意工坊三域布局：顶部创意参数条（风格/运镜/时长/画幅 + 摘要 + 插入到输入 + 重置）、左侧会话坞（可收起为 56px 轨）、中央创作流（对话核心 + 底部四模式输入栏）、右侧上下文检查器（Coze/单助手/工作流/协作编排四段）。
3. 底部四模式 Composer：Coze 创作 / 单助手 / 工作流 / 协作编排，各自独立草稿，切换不覆盖。
4. 十套主题重构：深空观测者/量子花园/星云漂流保留，其余七套换新主色与显示名（生物反应堆/极昼弧光/暗物质信标/磁暴极光/棱镜光晕/深渊生物光/极光冰晶）；主题 ID 全部保留，切换不失效。
5. Liquid Glass 功能层：导航/参数条/会话坞/检查器/输入栏/设置工作室使用三级渐进渲染（无 blur → CSS blur → Chromium 折射），正文消息/报告/表格保持稳定深色材质。
6. 壁纸：本机图片/视频（≤25MiB/150MiB、≤4096px、视频 ≤30s、仅 HTTPS URL）保存在当前设备 IndexedDB；cover 焦点拖动、压暗/渐晕、视频壁纸自动降低星尘粒子密度 40% 并在降级时暂停。
7. 能谱状态：idle/running/thinking/peak 由真实运行状态驱动（Coze 思考/任务、助手请求、工作流、协作、研究运行）；极昼弧光与磁暴极光主题下 peak 短暂脉冲（≤900ms）；禁循环轮播。
8. 宽幅个性化工作室（880px 模态）替代旧设置抽屉：左侧五分类（外观主题/壁纸与玻璃/界面效果/对话与工作流/导出与数据）+ 右侧实时预览（同款渲染组件）；focus trap + Escape + 未保存确认。
