# 研究历史恢复入口与 Web 浏览器回归

- **状态**：本批次已实现并验证；阶段四整体仍有未验收项
- **影响范围**：创意工坊研究工作流入口、研究运行恢复、插件 iframe 槽位尺寸、输出目录 lint 配置
- **分支**：fms-hermes
- **完成提交**：未提交

## 背景与目标

研究工作台已经将运行、计划和事件保存在服务端，但工作流模式没有入口重新打开账户已有运行。插件 UI 槽位在窄工作区下还存在 iframe 高度大于容器、按钮被裁切的问题。本批次补齐入口和布局，并对 Web 做完整回归。

## 用户可感知变化

- 登录用户可在创意工坊「工作流」模式打开「研究历史」，查看自己账户的运行状态、更新时间、完成步骤和来源数。
- 选择历史项会恢复对应服务端运行；本轮实际恢复到「计划待确认」状态，没有自动开始或调用模型。
- 960px 工作区下插件贡献卡片的 iframe 与容器高度匹配，槽位操作按钮完整可见。

## 实现内容

- 新增 `ResearchRunHistoryDialog` 及样式，支持加载、刷新、空态/错误态、键盘关闭和焦点约束。
- 将历史入口从 `ModelAssistantPanel` 传到 `CreativeWorkspace`；恢复时保存当前账户的 active run key 并打开对应研究工作台。
- 修正 `PluginSlot` 传给 `PluginFrame` 的高度，iframe 使用实际槽位高度，不再以固定最小高度撑开。
- ESLint 忽略生成目录 `output/**`，避免把插件验收产物当作应用源文件检查。

## 接口/数据/兼容性

只调用已有账户隔离的 `ResearchRuntimeAdapter.listRuns/getRun`；未改变服务端 schema 或历史记录格式。对话历史及研究记录仍归原账户所有。插件 iframe 只调整前端尺寸，不改变插件权限桥或工具契约。
