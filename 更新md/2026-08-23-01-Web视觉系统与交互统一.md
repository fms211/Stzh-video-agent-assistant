# Web 视觉系统与交互统一

- **状态**：已完成
- **影响范围**：Web 页面标题、主工作区输入区、协作编排控件、模型与角色中心
- **分支**：`fms-hermes`
- **完成提交**：未提交

## 背景与目标

本批次用于统一 Web 版各页面的标题、控件边框与交互动效，并修正主工作区中“对话”和“协作编排”彼此割裂的问题。

目标包括：

1. 页面级标题统一为可覆盖中文的像素字体、白字暖色辉光和流动像素点阵下划线。
2. 将协作编排并入主工作区底部输入区，通过“对话 / 协作编排”标签切换。
3. 为输入模式切换加入方向明确的弹簧缩放动效。
4. 将流动光边细化到指定控件，不用整块面板外圈代替控件反馈。
5. 同步优化“模型与角色中心”的卡片、输入控件、按钮、列表项和文字层级。

## 用户可感知变化

- 页面级大标题统一使用 Fusion Pixel Font 简体中文像素字体，显示为白字并带暖色多层辉光。
- 标题下方增加暖橙、冷靛、极光紫三色流动的像素点阵下划线。
- 主工作区底部输入区增加“对话 / 协作编排”标签；切换后在同一位置显示普通输入框或协作编排表单。
- “对话 → 协作编排”从下方弹出，“协作编排 → 对话”从上方弹入；减少动态效果偏好下由 MotionConfig 负责降级。
- 协作编排不再使用整块面板流动边框；流动光边应用到任务输入框和三个预算选项。
- “模型与角色中心”三张卡片增加环绕光边，表单控件使用流动光边，按钮增加上浮与按压反馈，按钮图标和文字统一居中。
- 模型、角色和插件列表项增加悬停上浮、边框提亮与暖色辉光反馈。

## 实现内容

### 标题视觉系统

- 新增自托管字体 `public/fonts/FusionPixel-12px-proportional-zh_hans.woff2`。
- 在 `app/globals.css` 注册 `FusionPixel-CJK`。
- 新增 `.page-title`：统一中文像素字体、36px 字号、白字、多层暖色辉光。
- `.page-title::after` 使用三色渐变、点阵遮罩和 `title-underline-flow` 动画形成流动下划线。
- 入口、欢迎页、主工作区、创意工坊、模型与角色中心、任务中心、工作统计、LibTV、画廊和活动统计等页面级标题接入统一样式。

### 主工作区输入编排

- `ChatFlow` 底部输入区改为“对话 / 协作编排”标签切换。
- 使用 `AnimatePresence` 与 `motion.div` 实现带方向的弹簧缩放切换。
- 协作编排使用 `CollaborativeRunPanel` 紧凑模式，不再作为主工作区上方的独立大卡片。
- 协作最终指令继续通过人工确认后投递到当前对话。

### 流动光边工具类

- 将 `.collab-border-flow`、对应关键帧和 reduced-motion 降级上提到 `app/globals.css`，供多个组件复用。
- 协作编排仅在任务输入框和预算选项使用控件级流动光边。
- 使用已注册的 `--glow-angle`、三色 conic-gradient 和遮罩合成保留细线边框效果。

### 模型与角色中心

- 三张 `.center-card` 接入 `edge-glow edge-glow-subtle`。
- 模型与角色表单的输入框、下拉框和文本域接入 `.collab-border-flow`。
- 刷新、验证、保存和 AI 生成等按钮接入 `.edge-glow--interactive`。
- 按钮统一为 12px/600，并使用 flex 居中图标和文字；标签统一 11px/500，输入正文统一 13px/400。
- 列表条目增加悬停上浮、边框提亮和辉光，减少动态效果时取消位移。

## 接口/数据/兼容性

- **API**：无新增或变更接口。
- **数据结构**：无数据库迁移，无用户数据变更。
- **字体资源**：新增约 896KB 的本地 WOFF2 字体文件；字体不依赖运行时外网加载。
- **兼容性**：流动边框依赖 CSS `@property`、conic-gradient 和 mask-composite；旧浏览器可能显示静态渐变或不显示动画，但不影响表单操作。
- **可访问性**：标签保留 `role="tab"`、`aria-selected`；动效提供 `prefers-reduced-motion` 或全局 MotionConfig 降级。
