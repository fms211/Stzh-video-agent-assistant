## 用户可感知变化

1. 模型与角色中心拆为「模型 / 角色 / 插件」三主标签；URL query `?center=plugins` 刷新恢复；模型表单、角色表单、write-only key、角色默认模型全部保留原位。
2. 插件标签四段 subnav：发现 / 账户插件库 / 项目插件 / 恢复与诊断；右侧固定项目选择器（project-a / project-b）与「从来源安装」。
3. 发现页：8 个演示插件卡片网格（已签名/未签名徽标、发布者、版本、权限档红色高亮、贡献数）+ 420px 详情抽屉（版本/ID/引擎/签名/权限/贡献统计）。
4. 安装向导四步 stepper：来源（市场/npm/Git/本地）→ Manifest/依赖/脚本 → 权限/沙箱 → 最终确认；未签名、开放互联网脚本、full tier、无强沙箱为独立风险行（勾选确认才能进入下一步）。
5. 账户插件库按 pluginId 分组多版本；显示 SHA-256、签名、安装时间、引用项目数；被引用版本卸载被阻止并列出引用项目。
6. 项目插件页：启用/禁用、固定版本切换、权限三档选择器（低于 manifest 最低档禁用并解释）、「等待重建 Generation」状态、Generation 面板（重建/安全模式/回滚健康快照）。
7. 恢复与诊断四区块：当前故障、疑似插件（一键禁用并重建）、健康快照（last-known-good 与历史回滚）、诊断日志（项目事件最新 200 条）；隔离数据 30 天保留，可恢复或二次确认永久删除。
8. 访客可浏览市场与各区域；安装、项目启用、恢复动作打开登录面板。
9. 6 个宿主页（首页欢迎/对话流/输入框/任务中心/画廊/工作统计）+ 模型中心声明了 additive PluginSlot（Mock 阶段无贡献时不渲染任何内容，视觉零变化）。

## 实现内容

**运行时层 `app/lib/plugin-center/`**（B-Task 10）：
- `types.ts` — 规划 §7.5/§8.2 契约逐字（PluginManifestV1 / PluginPackage / ProjectPluginBinding / PluginEvent / PluginGeneration / QuarantineEntry 等）
- `adapter.ts` — `PluginCenterAdapter` 接口（21 方法，含 changeProjectVersion 风险确认扩展参数）
- `mock-adapter.ts` — 确定性状态机：resolve→install（PREVIEW_HASH_MISMATCH 防重放）、多版本、项目 pin 不受新版本影响、PERMISSION_TIER_TOO_LOW、权限升级 RISK_CONFIRMATION_REQUIRED、被引用拒删、30 天隔离/恢复/永久删除、Generation starting→healthy/failed（crash 包触发 suspected 插件）、safe mode 空 binding、rollback 到历史快照、owner 隔离、dispose 幂等
- `mock-fixtures.ts` — 8 个演示插件（7 类场景全覆盖：已签名市场/未签名 npm/Git UI/本地 .stzhplugin/full 权限/权限升级对/Generation failed 包）+ 确定性演示哈希
