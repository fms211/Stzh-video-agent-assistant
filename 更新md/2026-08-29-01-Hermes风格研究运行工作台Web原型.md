## 背景与目标

按 `docs/superpowers/plans/2026-08-28-Hermes风格研究运行工作台-Web原型技术与执行规划.md` 阶段 A（Task 1–9）实施：在创意工坊内为「风格研究与应用」工作流提供接口就绪的运行工作台原型——计划生成 → 受控编辑 → 确认执行 → 事件投影驱动的运行视图 → 资料/产物/轨迹检查器。全部数据来自确定性 Mock Adapter，零真实模型/搜索/RAG 调用。

## 用户可感知变化

1. 创意工坊 → 单助手工作区 → 工作流 → 「风格研究与应用」：按钮文案由「开始执行」变为「生成研究计划」，点击后进入运行工作台（其余五个工作流行为不变，仍走原链式执行）。
2. 运行工作台内：中央主视图展示输入摘要、状态徽标、受控计划编辑（目标/预算/步骤排序/可选步骤开关/工具输入 JSON 编辑）；右侧四标签检查器（计划/资料/产物/轨迹）；顶部状态条提供确认/暂停/继续/取消/重试动作。
3. 运行完成后产物 tab 自动激活并显示数量徽标；三类演示产物（风格特征包 JSON / 研究报告 MD / 应用提示词包 MD）可复制、可下载；来源卡统一标注「演示来源」，资料 tab 顶部展示「外部资料不可信」安全提示。
4. 退出工作台回到原双区布局；Run 数据保存在 owner-scoped localStorage（`tszh:v2:<ownerScope>:research-runtime`），刷新页面后可恢复。
5. 其余页面（对话工作区、模型与角色、任务中心等）无任何可见变化。

## 实现内容

**新建运行时层 `app/lib/research-runtime/`**（Task 1–2）：
- `types.ts` — 规划 §3 契约逐字实现（ResearchRunSnapshot / RunEvent / PlanOperation 等，零依赖纯类型模块）
- `projector.ts` — 纯函数事件投影：seq 去重、gap→needsResync、非法跃迁抛 INVALID_STATE_TRANSITION、source/artifact 幂等 upsert
- `adapter.ts` + `adapter-types.ts` — `ResearchRuntimeAdapter` 接口（未来 HTTP Adapter 的共同契约）
- `mock-adapter.ts` — 确定性 Mock Runtime：createRun→plan（120ms）、步骤推进（150ms）、approve/pause/resume/cancel/retry/skip、PLAN_REVISION_CONFLICT、owner 隔离、跨实例恢复（实例重建时 recovering 续跑）、dispose 清理
- `mock-fixtures.ts` — 「赛博朋克 × 国产工业机器人 8 秒产品短片」演示数据：5 步计划、6 条来源（4 web + 2 rag）、3 个产物

**新建 UI 层 `app/components/research-workbench/`**（Task 3–6）：
- `layout-store.ts` — `useSyncExternalStore` 外部布局 store（Object.freeze 发布），1600/1366/1180/1024/960 五档响应式，中央最小 640px 保护，降级顺序固定（收提示词固定 → 压检查器 300 → 收检查器）
- `ResearchWorkbench.tsx` — 组合根：订阅 Run 事件、轻量投影更新快照、gap→全量重同步、完成时自动跳产物 tab
- `ResearchRunSurface.tsx` — 五种主视图（输入/规划中/待确认/运行暂停/失败恢复/完成），动作文案齐全（生成研究计划/确认并开始/暂停/继续/取消/直接重试/修改参数后重试/跳过并继续）
- `ResearchPlanEditor.tsx` — 受控计划编辑器，只产生五种 PlanOperation，revision 冲突提示
- `RunInspector.tsx` + `PlanTab` / `SourcesTab` / `ArtifactsTab` / `TrajectoryTab` — ARIA tablist + 键盘导航（Arrow/Home/End）、状态条不随标签滚动、Blob 下载后 revoke、外链 `_blank noopener noreferrer`、轨迹 200 条渲染上限 +「加载更早记录」
- `PromptRail.tsx` — rail/overlay/pinned 三态，Escape/外部点击只关 overlay，焦点返回触发按钮
- `ResearchWorkbench.css` — 复用全局 token（--glow-warm/cool/aurora、--space-* 颜色、--motion-*），响应式 1280/1024 断点，prefers-reduced-motion 与 data-reduced-motion 双机制降级

## 已知限制

1. Mock 演示步骤间隔 150ms，完整运行约 1 秒即到完成态——「暂停/继续」在浏览器中难以手动捕捉，仅单元测试覆盖。
2. `applyEventToSnapshot` 是展示级轻量投影（组件端），与 `projector.ts` 的完整投影并存；未来 HTTP Adapter 接入时组件端应改用 projector 统一处理。
3. PromptRail 固定态宽度拖拽（Pointer handle）尚未接通（store 已支持 setPromptWidth，UI 手柄未渲染）——规划 Task 6 范围内列为可接受裁剪，后续补。
4. 会话中热重载会重置工作台本地状态（Next dev 特性），生产构建不受影响。
5. 阶段 B（Task 10–15 插件中心原型）、阶段 C（Task 16–20 后端）未开始。
