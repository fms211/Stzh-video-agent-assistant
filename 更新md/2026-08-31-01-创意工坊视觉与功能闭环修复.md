## 接口/数据/兼容性

- **后端 API**：无新增接口；登录仍使用 `/api/auth/login` 与 `/api/auth/me`。
- **本地数据**：继续使用 `tszh-personalization/wallpapers` IndexedDB、`tszh:v2:<owner>:wallpaper-appearance`、`tszh:v2:<owner>:glass-settings` 和 `workspace-layout`；不上传壁纸 Blob，不删除会话/任务/协作数据。
- **主题**：原十个 theme ID 与既有 `theme` key 保持不变；未知 ID 回退 `deep-space`。
- **兼容性**：无 backdrop-filter → tier 0；Safari/Firefox → CSS blur；Chromium → blur + 独立边缘折射；reduced-motion 停止视频/Three 动效并关闭折射。
- **安全**：壁纸 URL 仅接受 HTTPS 且拒绝 URL 用户名/密码；账户/访客 IndexedDB 记录按 owner 双重过滤。
