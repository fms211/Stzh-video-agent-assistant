# 项目更新长期记录

本目录是腾昇智和项目**所有未来更新**的长期记录，不只服务当前问题 1–7 或某一轮视觉调整。每个完成、暂停或回滚的批次都应新增一份独立 Markdown 文档，并更新下方索引。

## 记录规则

1. 新建记录前复制 [模板.md](./模板.md)，按实际情况填写；不把计划、猜测或未执行的测试写成完成事实。
2. 文件名使用 `YYYY-MM-DD-序号-简短主题.md`，同日序号从 `01` 开始递增。
3. 索引按日期与序号倒序排列；新记录放在最上方。
4. “提交”列写实际提交哈希；尚未提交时明确写“未提交”，不要伪造提交信息。
5. 涉及接口、数据迁移、兼容性、测试或回滚风险时，必须在记录正文说明。
