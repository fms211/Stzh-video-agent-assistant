# 移除 LibTV 页面与入口

- **状态**：已完成
- **影响范围**：Web 导航、页面切换、起始页设置、产品与设计说明
- **分支**：fms-hermes
- **完成提交**：未提交

## 背景与目标

用户明确要求去掉 LibTV。本次移除该占位模块，并将 LibTV 真实接入从阶段四 Web 收尾范围中剔除。其他 Web 功能补齐、首页风格完善、Coze 全链路测试仍属于后续收尾工作；手机端开发留到阶段五。

## 用户可感知变化

导航保留创意工坊、模型与角色、任务中心、工作统计、创作画廊五个页面。起始页设置不再显示 LibTV，旧 LibTV 起始页自动回到创意工坊。

## 实现内容

- 删除 LibTVPanel 组件及 HomeClient 动态导入、页面渲染。
- 同步移除 NavigationBar、PageTransition 中的页面项，保持页面与导航顺序一致。
- 移除 SettingsDrawer 对应选项，更新起始页类型与读取迁移逻辑。
- 更新现有迁移及导航契约测试、PRODUCT.md、DESIGN.md；历史开发记录保持原状。

## 接口/数据/兼容性

无服务端 API 或数据库变更。旧 `libtv` 值读取时映射为 `studio`，读取不写入存储，其他偏好保留；后续用户保存偏好时按原有流程保存。未改动手机端或用户会话、任务、附件数据。
