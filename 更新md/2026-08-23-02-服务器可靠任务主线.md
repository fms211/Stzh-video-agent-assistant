# 2026-08-23 · 服务器可靠任务主线

## 目标

把已经验证过的 SQLite 租约队列、Agent Service、附件服务和 `video.generate` 执行器真正接入生产启动入口，使“桌面创作中心 + 手机远程控制台”围绕同一条服务端任务主线运行。

## 已完成

- 新增统一 `task-runtime-bootstrap.js`，只领取 `execution_mode=server` 且 `kind=video.generate` 的任务；全局并发 2、单账户并发 1。
- `server.js`、云端 `start.js` 和 Electron 内嵌 Express 都创建同一套 Runtime，并在关闭时释放租约。
- Electron 35 使用独立的 `server/native/electron-v133/better_sqlite3.node`，Node 25 独立服务继续使用 ABI 141；数据库加载器按运行时 ABI 选择，避免两种启动方式相互破坏。
- 缺少 Coze token/bot 配置时 Runtime 不领取任务，任务安全保持排队；`/health` 返回 Runtime 是否启用、活动数量和禁用原因。
- 桌面任务中心改为观察与控制端，不再使用 `/claim` 执行生成，避免与服务端 Worker 抢任务。
- HTTP 和 WebSocket 的暂停、取消会中止正在运行的 Agent 请求；继续、重试会唤醒 Runtime。
- 桌面先注册稳定设备 ID，再进行心跳与带设备身份的 WebSocket 连接；同一设备 ID 不能被另一账户接管。
- ChatFlow 改为“上传附件 → 创建幂等任务 → 查询阶段 → 展示最终结果”，不再直接把 multipart 发给 `/api/agent`。
- 协作编排会保存用户最后编辑的最终指令，原子创建唯一任务并返回 `taskId`；只有任务完成后才写入真实完成时间。
- 协作启动用状态 CAS 防止并发点击产生重复模型调用。
- OPC 风格、运镜、参数、时长和画幅会进入右侧模型助手的系统上下文。
- 项目可在协作面板选择个人角色编队；角色提示词会驱动对应 LangGraph 阶段，角色默认模型也会实际参与调用。
- 模型地址默认拒绝 localhost、环回和私网字面地址；部署者确需使用本地模型时显式设置 `STZH_ALLOW_PRIVATE_MODEL_URLS=1`。
- Geist、Geist Mono 和展示字体全部改为仓库内本地文件，生产构建不再依赖 Google Fonts 网络。

## 数据变化

- `agent_runs` 新增 `task_id`，用于协作运行与可靠任务的真实关联；旧运行记录不删除。
- 新增索引 `idx_agent_runs_task`。
- 任务输入中的 `sourceAgentRunId` 用于把 running、paused、completed、failed、cancelled 状态回写到协作运行。

## 测试

- Runtime 生产装配：仅执行受支持的服务器视频任务；缺配置时零领取。
- 三个启动入口静态接线与关闭生命周期测试。
- HTTP/WS pause、cancel、resume、retry 与 Runtime 的中止/唤醒测试。
- 桌面设备注册、心跳、跨账户防劫持测试。
- 协作人工编辑、幂等任务创建、状态关联和并发启动单次计费测试。
- 自定义项目角色、角色阶段提示词和默认模型上下文测试。
- 当前 `npm run test:p0`：根项目 28/28，服务端 82/82。
- Web 与移动端 TypeScript 均通过。
- `npm run lint` 退出 0（保留 82 条既有视觉层告警）；最终 `npm run build` 在离线字体条件下通过并生成 9 个页面。

所有 Agent/模型测试均使用注入 mock、假密钥或 `.invalid` 地址，没有访问真实 Coze 额度。

## 运维与回滚

- 未配置 Coze 时服务仍可启动、登录、配对和管理任务，只是不自动消费生成任务。
- 回滚 Runtime 入口前应先调用 `stop()`；SQLite 中的排队任务、附件和协作记录保留，不做删除性回滚。
