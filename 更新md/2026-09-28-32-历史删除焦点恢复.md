# 第32批：历史删除后恢复键盘焦点

日期：2026-09-28。范围是 Web 创意工坊会话坞的历史列表。

键盘删除历史行后，原删除按钮会从 DOM 中移除，导致焦点丢失。现在删除后若仍有相邻可见会话，焦点落在相邻行的删除按钮；若删到最后一条，焦点落在“新对话”。鼠标删除不强制改动焦点。顺手去掉了侧栏旧开关的一条未使用参数警告。

隔离预览浏览器验证：先删除唯一一条空会话，确认“新对话”获得焦点；再通过本地账户 API 创建两条零消息合成会话，回车删除首条后第二条删除按钮获得焦点，空格删除第二条后“新对话”获得焦点。两条合成会话均已由页面删除；未发出模型或媒体生成请求。

同一最新构建还复核了协作编排历史：20→22 条分页加载、末页“草稿 20”检索与只读恢复通过；复制任务到新讨论后，文本在刷新并重新进入协作模式时保留，未启动讨论。列表在复制操作后重载首20条，检索词虽保留但末页记录须重新点“加载更早记录”；这是当前“搜索已加载记录”范围，不能算全库搜索。导出文件落盘仍未验收。

验证结果：`npm run test:p0` 726 项通过（Web 452、服务端 274）；同源生产构建和 TypeScript 通过；定向 ESLint 0 错误、0 警告；只读冒烟 27 项、记忆存储冒烟 31 项通过，媒体生成调用 0。日志为 `output/stage4/batch32-regression.log`、`batch32-build.log`、`batch32-readonly-smoke.log`、`batch32-memory-smoke.log`。
