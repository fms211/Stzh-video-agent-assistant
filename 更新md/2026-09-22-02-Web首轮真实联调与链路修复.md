# Web 首轮真实联调与链路修复

- **状态**：本批次已完成；阶段四整体进行中
- **影响范围**：Web 创意工坊、导航、画廊、Coze 服务、任务会话隔离及测试
- **分支**：fms-hermes
- **完成提交**：未提交

## 背景与目标

按用户授权开始阶段四：Web 五页面全功能收尾、首页风格完善、Coze 全链路验收。LibTV 已移除，手机端留至阶段五。本批次先建立基线、修复真实调用暴露的问题，不将原型或聊天完成状态当作全部业务验收通过。

## 用户可感知变化

1. 五个导航入口常驻，账户和通知不再依赖悬停展开，保留原有深空、水玻璃和发光边缘。
2. 输入框选择的附件实际进入上传、任务和 Coze 链路；生成期间避免重复提交，访客拦截时保留输入。
3. 同一个本地会话正确续接服务端记录的 Coze 会话，不同账户隔离。
4. Coze 断流、业务错误、取消、等待外部动作、空产物和下游模型失效不会被正常聊天结束掩盖；有替代产物时保留能力失败警告。
5. 失败任务及时结束前端等待，不再被错误地当作网络重试持续轮询。
6. 画廊分页读取服务端已完成任务，并与本地作品合并去重，增加原文件入口。
7. 修复签名媒体链接尾部混入 Markdown 右括号导致无法播放的问题，兼容旧记录。
8. 修正布局宽度预算，计算真实边距、列间距和右栏；960px 窗口收起左坞，避免发送按钮被遮挡及参数摘要竖排。

## 实现内容

- `server/account-agent-service.js`：SQLite 远端会话映射、账户派生 user_id、同会话并发保护、取消后拒绝写入映射。
- `server/agent-service.js`：完整结束事件判定、Coze done 标记兼容、多个回答聚合、工具产物与错误识别、历史去重和 URL 解析。
- Agent JSON/SSE 路由和生产任务 Runtime 复用账户服务边界。
- `app/lib/wait-for-task.ts`：区分终态业务错误与暂时网络故障。
- `app/lib/workspace-media.ts`：任务媒体投影、分页、去重、旧链接兼容和过期账户请求结果丢弃。
- 导航、输入附件转交、生成禁用状态、画廊和响应式布局对应接线。
- README 修正 Coze 令牌变量名称及前后端配置位置。
- 新增隔离验收脚本 `scripts/stage4-coze-smoke.cjs` 和 `scripts/stage4-coze-workflows.cjs`。

## 接口/数据/兼容性

- 新增 `coze_conversation_links` 表，主键为账户、服务地址/Bot 命名空间、本地会话 ID；不保存访问令牌。
- Web 任务输入中的 `conversationId` 继续表示本地会话；由服务端映射为真实 Coze conversation_id。已有错误直传记录不冒充有效远端映射，首次新调用创建正确映射。
- Agent 输出可选增加 `warnings`，成功时原有字段保持兼容。
- 使用 `output/stage4/isolated-data/` 独立数据库及合成测试账户；未启动主数据库的任务 Runtime，也未清理生产数据。
- 用户提供的新 Coze 令牌仅更新本机 `server/.env.local`，已验证该文件被 Git 忽略；验收记录不包含令牌。
- 手机端代码未修改。现有与本批次无关的未提交成果保留。

## 已知限制与下一批

用户在本批次结果汇报后明确要求先不处理图片/视频下游额度和效果问题。相应真实生成规格与外部模型条目转为暂缓验收，不再重复生成消耗额度；Web 开发继续。实际模型失效和空产物记录仍保留，不能与用户说明的额度限制混为同一已证实原因。

- 研究工作台和插件中心仍需真实服务接入，当前 Mock 不能计入完成。
- 单助手、协作与研究的独立模型配置待用户指定或在页面配置；模型服务的真实验收未完成。
- 6 个 Coze 插件工具尚未逐项完成独立验收；图片识别和风格工具已有部分调用证据。
- 下游模型失效需在 Coze 更新模型并发布；连贯模式空产物和生成时长不符需继续定位。
- 所有主题、不同账户切换、后台任务回到对话、完整下载行为及性能门禁还需要后续浏览器回归。
- 开发服务器热更新期间出现内存分配错误，已停止该预览，改用生产静态构建完成上述画廊与布局检查；没有把开发态故障当作已根治。
- 此处已验证的生产页面不代表全部功能定版，阶段四目标保持进行中。
